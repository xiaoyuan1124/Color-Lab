# App Review Notes — Color Lab 1.0

Color Lab is a Local-first color design utility. No account or login is required.

## Suggested review path

1. Open 配色 (Compose).
2. Choose or enter three colors. The roles stay fixed as Base 75%, Structure 18%, Accent 7%.
3. Open 進階分析 to review contrast, WCAG, color-vision simulation, tone relationships, context previews and professional handoff.
4. Open 相片 (Photo) and choose 拍照取色 or 從相簿選擇. Photo analysis runs on device.
5. Open 收藏 (Library) to save palettes and search locally.
6. Use 匯出 to inspect CSS, Design Tokens, SVG, LAB D50, CMYK reference and Display-P3 output.

Core functionality is bundled inside the app and does not require a remote website or user account.

Camera and Photo Library permissions are requested only after the reviewer taps the corresponding Photo action.

Color Lab does not include advertising, analytics, tracking, cloud sync, or a Color Lab backend.
