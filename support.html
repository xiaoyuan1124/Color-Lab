Color Lab 支援

Color Lab 是 Local-first 的三色配色研究與交付工具。核心流程：Feel → Understand → Explore → Compare → Validate → Apply。

常見問題

資料會上傳嗎？
核心配色、收藏、專案與照片取色都以裝置本機處理為原則，不需要登入。

75 / 18 / 7 代表什麼？
Color 1 = Base 75%，Color 2 = Structure 18%，Color 3 = Accent 7%。使用者自行輸入三色時不會被重新排序。

為什麼 CMYK 只標示參考？
實際印刷會受到印刷設備、紙材與 ICC profile 影響；Color Lab 的 CMYK 是從螢幕 sRGB 推導的參考值。

如何回報問題？
請在公開 GitHub repository 的 Issues 回報，附上裝置型號、iOS 版本、重現步驟與畫面截圖（請避免附上私人資訊）。
