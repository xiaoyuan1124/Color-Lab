# Color Lab

手機優先的私人配色實驗室。

核心流程：給我一個顏色 → 延伸 Base / Structure / Accent → 75 / 18 / 7 預覽 → 收藏。

V0.1
- 手機色盤 + HEX 輸入
- 安靜 / 溫暖 / 冷調 / 精品 / 自然 / 大膽
- 自動產生 Base / Structure / Accent
- 可獨立更換三種角色
- 75 / 18 / 7 視覺比例
- localStorage 收藏
- PWA，可加入 iPhone 主畫面
- 無登入、無後端、無 Supabase


## V0.5 Color Intelligence
- 1–3 色輸入；缺色時提供感知式補色建議
- Color.js：OKLCH / 感知色彩計算（MIT）
- Poline：Anchor-based palette journey（MIT）
- Color Thief：照片自動抽主要色票（MIT）
- 所有既有手動 HEX、色盤與精準照片取色仍保留
