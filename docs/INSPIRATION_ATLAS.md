# Color Lab Inspiration Atlas

The V2.7 atlas is a local, authored relationship library.

It is **not** a list of official brand palettes. Each record contains a three-role sample, a lane, a short relationship explanation, and a novelty prior. The runtime transfers the sample's relative color relationship onto the user's selected seed color.

Current lanes:
- editorial
- atmospheric
- fashion
- expressive
- unexpected

The goal is to store **relationships**, not fixed HEX answers. The recommendation selector can therefore force cross-lane variety instead of returning five neighboring high-score palettes.
